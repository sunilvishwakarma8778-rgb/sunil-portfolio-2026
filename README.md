# Sunil Vishwakarma — 3D Scroll Portfolio

React + Vite + Three.js (react-three-fiber) + GSAP ScrollTrigger.

## Run
```bash
npm install
npm run dev
```
Open the URL Vite prints (usually http://localhost:5173).

## Edit
- All text, dates, links, projects: `src/data.js`
- Your photo: put it in `public/` and set `photo` in `src/data.js`
- Colours / layout: `src/styles.css`
- 3D shapes and scroll behaviour: `Shapes()` in `src/App.jsx`

## Deploy (Vercel)
Import the repo on vercel.com — framework preset "Vite", no extra settings.
